Raw availability includes Usenet/NZB indexers only (Prowlarr protocol = Usenet/Newznab). Torrent indexers are deliberately excluded. Raw availability is measured before Arr's Custom Format score, size, language, release-group, retention, or other acceptance/rejection rules. A correct-media candidate still counts when Arr later rejects it; an explicit wrong-media parse is excluded. New searches use time-bounded Sonarr/Radarr API profile snapshots. Historical searches can also be reconstructed from Arr's retained per-release quality-profile decisions: qualities explicitly marked “not wanted in profile” are excluded, while correct-media candidates that passed the quality check still count even if Arr later rejected them for another reason. Searches without either form of evidence remain unresolved.
